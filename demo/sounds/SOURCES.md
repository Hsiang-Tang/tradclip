# Sound sources

All samples are CC0 (Creative Commons 0, public domain dedication) recordings from
Freesound; the license was read on each sound page. Cut from the site's public hq
preview MP3 (decoded to 48 kHz mono 16-bit WAV, 1 ms fade-in, 3 ms fade-out,
peak-normalized to -1 dBFS). Times are positions in the preview file.
